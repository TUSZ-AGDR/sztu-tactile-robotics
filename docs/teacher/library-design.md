# DexH13 课程触觉实验库：第一版设计

本文记录设计访谈结果，是待实现的规格。文中的课程 API 为拟议接口。

## 目标与范围

学生在自己的电脑上编辑 Python 脚本，改一两行参数或控制逻辑，即可运行、观察并比较触觉抓握实验。基于现有 `dexh13-tactile-sim-dex13simv1/dexh13sim` 增加课程层，复用当前手模型、触觉生成、数据记录和回放能力。

第一版固定使用 DexH13，手的位置固定。提供方块、圆柱和球三个物体预设，每个预设包含经过验证的尺寸、初始位置、手姿态和关节协同。学生可修改物体质量、摩擦系数、目标抓握力，或替换控制策略。

实验流程：重置 → 支撑物体 → 闭合手指 → 按场景规定的时刻撤去支撑 → 保持 3 秒 → 评分。保持阶段支持一次可开关、固定时刻和大小的向下拉力。各策略使用相同释放时刻、扰动计划与评分条件。

成功条件同时包含物体保持在允许区域内、握力指标未超过场景规定上限。学生目标力与评分上限分开设置。

## 学生接口

参数实验示意（数值仅演示接口，默认值须通过场景测试确定）：

```python
from dexh13sim.course import Experiment

experiment = Experiment(
    object_name="box",       # box / cylinder / sphere
    target_force_N=3.0,       # 学生修改的目标力
    mass_kg=0.05,
    friction=0.8,
    disturbance=True,
)
result = experiment.run(controller="tactile")
```

策略实验示意：学生函数输出每秒闭合变化量，正值收紧、负值放松、零值保持。使用速率而非每步固定增量，使策略含义不随控制频率改变。

```python
def policy(obs):
    error = obs.target_force_N - obs.grip_force_N
    return 0.2 * error

result = experiment.run(controller=policy)
```

库负责将闭合速率积分为 `[0, 1]` 的闭合量，再通过预设映射到关节目标；统一限制动作速率与范围，检查非有限值，重置控制器状态。

公开观测包含仿真时间、实验阶段、闭合量、最新触觉帧及其时间戳、各传感器力指标、总握力指标和目标力。物体真实位姿用于评分、可视化与记录；基础策略模板以触觉为反馈。

内置两个基线：

- `fixed`：按预定动作闭合到固定量后保持，忽略触觉反馈。
- `tactile`：依据目标力反馈调整闭合量，提供增益、死区和速率限制。

提供独立的 `examples/course/parameters.py`、`policy.py` 和 `compare.py`，分别对应调参、策略修改与同条件基线比较。

## 模块职责

课程模块放在 `dexh13sim/course/`，拟议结构如下：

| 模块 | 职责 |
| --- | --- |
| `experiment.py` | 高层运行接口、生命周期、无界面运行、结果返回 |
| `scene.py` | 加载预设、设置质量和摩擦、启用重力、管理初始支撑与扰动 |
| `hand.py` | 统一闭合量到 DexH13 关节目标的映射 |
| `observation.py` | 触觉观测、时间戳、握力与每传感器指标 |
| `controllers.py` | 固定闭合、触觉反馈和学生函数适配 |
| `viewer.py` | 三维热力图、二维展开图、曲线和实验状态 |
| `evaluation.py` | 保持时间、掉落、力上限、失败原因 |
| `results.py` | 保存曲线、配置与结果，衔接现有 episode 记录 |

仿真与评分可在关闭界面时运行。可视化消费观测与记录，界面刷新频率不决定物理步进、控制或评分频率。重置时清空采样缓存、随机状态、策略状态和曲线。

## 可视化

同一实验窗口包含：

- 三维手和物体，并在手表面显示 taxel 颜色。
- 选定传感器的二维触觉展开图，可切换传感器。
- 握力随时间变化曲线，叠加目标值与评分上限。
- 物体高度曲线，并标记撤支撑与扰动时刻。
- 实验阶段、保持时间和最终结果。

三维与二维热力图使用一致的固定色标，显示数值范围与单位 N。默认展示压缩法向力，可扩展查看切向分量。二维图根据模板点的几何位置布局，不将 1140 点张量直接 reshape 为任意矩阵。各传感器展开坐标需要离线验证，避免曲面投影造成重叠。

MuJoCo 具有二维图表绘制接口 `mjr_figure`：https://mujoco.readthedocs.io/en/latest/APIreference/APIfunctions.html#mjr-figure 。同窗口曲线和图像叠加按选定发行版的 viewer 能力实现，并固定经测试的版本。macOS GUI 启动需要处理 `mjpython`；统一启动入口应封装平台差异。

## 现有工程需要补齐的关键能力

1. **真实的保持实验。** 当前 `hand.xml` 的重力为零，`free_object_scene.xml` 的小球通过 weld 连接 mocap 目标。新增独立课程场景，启用重力，在释放阶段解除支撑约束。保持阶段物体只能依靠实际手物接触保持。配置手朝向与物体位置，确保手掌或环境不会托住物体而导致虚假成功。
2. **可验证的物体预设。** 为每个预设分别验证抓取姿态、接触位置、关节协同与可行参数范围。统一闭合量不会自动适配任意形状或尺寸，第一版保证三个预设及其明确支持的参数范围。
3. **明确的握力口径。** 现有 `summarize_raw` 使用三轴向量模长求和，不能直接称为总法向握力。课程层需明确压缩方向、目标物体接触筛选、各传感器聚合方法与单位。将握力定义为指定抓握传感器上的压缩法向读数之和，并标明它是课程用触觉指标。法向符号与聚合结果须通过简单接触用例验证。
4. **独立评分。** 掉落判断依据物体位姿和持续时间。超力评估使用未加噪声、未裁剪的对应原始指标，避免噪声配置或输出饱和改变评分。记录峰值与超限持续时间，固定每个场景的限值和瞬时尖峰处理规则。
5. **闭环采样。** 当前正式触觉输出为 10 Hz，需要验证该采样与滤波延迟是否适合课程闭环。控制频率、触觉频率、物理频率和界面频率分别配置，策略只能消费已产生的触觉帧。根据稳定性、超调和本地性能测试确定默认值。
6. **可安装的资源。** 当前配置、模板和模型多依赖相对工作目录。将模型、mesh、模板和预设作为安装资源提供，通过包资源路径加载。验证从任意目录启动，避免要求学生进入源码目录。

当前触觉来自 MuJoCo 刚体接触与空间分配，是教学用工程近似。讲义需解释空间扩散与真实传感器之间的区别，实验结论限定在这个模型和参数范围内。

## 开发顺序

1. 建立一个开启重力、能够撤支撑的方块场景，调通统一闭合量与两个基线。先验证保持与掉落都能真实发生。
2. 接入课堂观测、阶段管理、扰动与独立评分，确定力口径与采样默认值。
3. 完成固定色标三维热力图、二维展开与实时曲线，验证界面开关不改变实验结果。
4. 加入圆柱和球预设，逐一验证默认抓握和可行参数范围。
5. 完成资源打包、跨平台启动入口、三个学生脚本与课程说明，测试干净环境安装。

## 验收条件

- 三个物体的默认配置均能完成规定保持，且满足力上限。
- 故意设置过小闭合量能出现真实掉落；过大闭合量能触发超力失败。
- 撤支撑后无残留 weld、mocap 支撑或物体位姿强制更新。
- 两个基线在相同配置、释放计划与扰动条件下可重复比较；记录结果，不预设触觉策略一定胜出。
- 开关 GUI 后，确定性实验的主要指标一致。
- 学生改一个物体名即可切换预设，改一个参数即可完成参数实验，修改短策略函数即可完成进阶实验。
- 热力图保持固定色标，曲线使用一致的力定义和单位，并显示触觉时间戳与事件时刻。
- 安装后从任意工作目录可启动；关闭界面、重置与连续运行均不残留实验状态。
- 在实际支持的 Windows、macOS、Linux 环境分别记录 GUI 与无界面测试结果，未验证的平台明确标注。
