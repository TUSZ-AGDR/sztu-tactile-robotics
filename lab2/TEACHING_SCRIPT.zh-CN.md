配合 [中文 README](README.zh-CN.md) 或 [英文 README](README.md) 使用。演示时以 README 为主，下面的口语稿可以直接照着说，也可以按自己的习惯删减。

## 1. 开场：今天要做什么

**操作：** 打开 README 顶部，指出学生只需要修改两个文件。

> 今天我们做一个简单的触觉抓握实验。让仿真里的手夹住一个物体，看看它能不能抓稳。
>
> 大家今天只需要改几个数字，再重新运行，观察结果怎么变化。
>
> 主要改两个文件：`parameters.py` 用来换物体、改力度、重量和摩擦；`student_policy.py` 用来决定手收到触觉反馈之后，收紧还是放松。

## 3. 认识窗口：每张图在看什么

**操作：** 先让实验运行到结束，保留窗口，然后指着各部分解释。

> 先看三维画面。手从关节零位开始，进入准备姿态，再用拇指和食指夹住物体。
>
> 前面几秒，物体有一个初始支撑。第 4 秒，这个支撑会撤掉。从这个时候开始，我们看手能不能靠接触和摩擦继续握住物体。默认后面还有一次轻微的外力拉动。
>
> 手上的彩色小点是模拟触觉点，表示这个位置受到的接触力。对照右侧色条看：紫蓝色受力小，黄红色受力大，红色是色条的最高端。这些数值是根据仿真接触力计算出来的。

**操作：** 指向右侧最上面的热力图。

> 这张图是选定的一块触觉区域摊开后的样子。三维上的点和这里的点显示的是同一份触觉数据，只是观察方式不同。
>
> 它主要帮我们看：物体碰到了哪里，受力集中在哪些位置。

**操作：** 点击三维窗口，按 `N` 切到下一块传感器，按 `P` 切回。看图上方的传感器名称，找到有接触颜色变化的区域。

> 可以切换不同的触觉区域。没有接触物体的区域，颜色变化不明显，这是正常的。

**操作：** 指向热力图下面的两张曲线。

> 第一张是抓握力度。横轴是时间，蓝线是实际测到的力度，绿色虚线是我们设定的目标，红色虚线是允许的上限。
>
> 我们看蓝线有没有接近目标，以及它是不是一直在明显波动。设成 4 牛顿，实际力度也会有变化，不会每一刻都刚好等于 4。
>
> 最下面是物体高度。第 4 秒之后，高度基本保持住，说明物体没有明显往下掉；如果曲线往下走，就要结合三维画面看它是不是滑落了。红色虚线标出实验使用的掉落判定高度。
>
> 所以，看动作就看三维画面，看接触位置就看热力图，看用力大小就看力度曲线，看有没有掉就看高度曲线。

## 4. 换一个物体

**操作：** 关闭窗口。在 `parameters.py` 中只把 `OBJECT_NAME` 改为 `"sphere"`，保存，再运行同一条命令。

## 5. 改力度，再改反馈速度

**操作：** 先恢复方块、4 N、0.03 kg、摩擦 1.0、`GAIN = 0.1`。然后只将 `TARGET_FORCE_N` 改为 `2.0`，保存并运行。看完可再试 `6.0`。

> 现在我们改目标力度。数字大一些，策略就希望手抓得更用力。
>
> 先看绿色目标线怎么变，再看蓝色实际力度有没有跟着变。力度变小不一定就会掉，力度变大也不代表一定更好，要看实际结果。

**操作：** 将目标力度恢复为 `4.0`。打开 `student_policy.py`，展示函数，然后只把 `GAIN` 从 `0.1` 改成 `0.3`，保存并运行。

```python
def policy(obs):
    error = obs.target_force_N - obs.grip_force_N
    return GAIN * error
```

> 这个函数做的事情很简单：把目标力度减去当前测到的力度。
>
> 当前力度不够，结果是正数，手就继续收紧；当前力度太大，结果是负数，手就放松一点。
>
> `GAIN` 决定调整的快慢。我们把它调大，看看手的反应和力度曲线怎么变化。调得更快，也可能出现更明显的波动，所以大家要看结果。
>
> 这一轮只改 `GAIN`，不要同时改力度或摩擦，这样才知道变化是由哪个数字引起的。

## 6. 做一次明显滑落

**操作：** 关闭旧窗口，将两个文件设为以下参数，保存后运行。

`student_policy.py`：

```python
GAIN = 0.3
```

`parameters.py`：

```python
OBJECT_NAME = "sphere"
TARGET_FORCE_N = 2.0
MASS_KG = 0.03
FRICTION = 0.05
```

> 接下来用一组准备好的参数看滑落。我们选球，目标力度是 2 牛顿，并把摩擦系数降到 0.05，让表面变得很滑。
>
> 特别注意第 4 秒。支撑撤掉之前，物体待在那里还不能说明抓稳了；支撑撤掉之后，才看得出来。

**操作：** 运行到结束，指出球下落的画面和高度曲线下降的位置。

> 这里球往下滑了，高度曲线也跟着下降。触觉上有接触、有受力，并不代表一定能抓稳，还要看摩擦等条件。

**操作：** 只把 `FRICTION` 改回 `1.0`，其余参数不变，再运行一次。

> 现在只恢复摩擦，比较两次结果。大家重点看第 4 秒之后的高度曲线，以及球是否还留在手里。
>
> 这就是我们做小实验的方法：改一个条件，再看现象有什么不同。
